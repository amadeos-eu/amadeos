# Horizon Dark screenshots: shot list

**167 shots** (68 of them for the website), replacing about 315 pictures.

Everything that shows a program or a dialog is shot in **Horizon, Dark scheme**, including the pictures that were already Horizon (icons and style have changed since). One shot often serves the website and both handbooks; I crop, scale and convert it for each place.

## How to take them

- Settings > Desktop look: **Horizon, Dark**, default accent. Language English, user `alex`, computer name `amadeos`, demo data (no private mail, names or networks).
- **Window shots:** amade-screenshot in window mode (with the window frame, no desktop around it). Usual window size about 1000 x 720 unless the program has its own size.
- **Whole-screen shots** (marked *screen*): 1280 x 800 or 1440 x 900.
- Save as PNG with **exactly the file name below** (e.g. `files-tree.png`) in one folder, e.g. `~/Pictures/horizon-shots/`. When it's full, I copy the folder from your computer (I ask once for access); uploading here works too, then please write the numbers in the message.
- ★ = the website needs it. If you want to do it in rounds: all ★ first, then the rest.

## Stays as it is

- Pictures of Classic-only parts: Front Panel, drawers, CDE window frame and menus, palettes (Color), backdrops, the Classic login and lock screens, Front Panel cells, and chapter 21 (the Classic tour). The website's `classic.html` keeps its Classic pictures too.
- The wallpaper collage in chapter 29, the games (they draw themselves) and print previews.
