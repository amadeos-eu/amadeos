## amadeOS image and User's Handbook

### amadeos [1.0.0](https://github.com/amadeos-eu/amadeos/releases/tag/v1.0.0)

#### Features

- **build:** show build duration in build.sh and buildDistribution.sh
- **lock:** screen lock as its own process with input grabs
- **dm:** run each login in its own root session worker
- **lockscreen:** implement screen locker with PAM authentication and Super+L shortcut
- implement milestone M11 virtual workspaces and desktop root window menu
- **panel:** add runPanel gradle task, Escape key binding, and custom positioning options
- **panel:** move clock to outer left, add analog CDE clock with style context menu
- **panel:** redesign middle workspace switcher with flat Lock and Exit buttons and authentic CDE styling
- **panel:** remove redundant right border from terminal button
- **panel:** remove redundant right border from trashcan button
- **panel:** restyle CDE front panel with flat launcher buttons, 3D drawer triangles, and side grip ribs
- **ui:** add central AmadeUI 3D Motif styling and swing.properties configuration
- **xdg:** implement Freedesktop .desktop parser, dynamic drawer population, and drop-in .deb support (M10)
- **locale:** configure default German UTF-8 locale across systemd and Display Manager
- **dm:** implement Java Display Manager with PAM authentication and Motif greeter (M9)
- **settings:** introduce DazeSettingsApplication and WallpaperManager for desktop wallpaper and theme control
- **theme:** add central theme engine, pixmap icons, and modular dock widgets
- **scripts:** add run-xephyr.sh for instant nested X11 testing without ISO builds
- **desktop:** implement CDE Front Panel dock and top-left vertical icon tiles
- **scripts:** add run-qemu.sh helper script
- **panel:** implement Milestone M8 desktop panel dock with live taskbar, start menu, and minimize/restore
- **wm:** add inner perimeter groove to place border surface on same level as buttons and titlebar
- **wm:** add authentic Motif 3D beveled styling and wireframe dragging
- **wm:** implement server-side Motif window decorations and reparenting (M7)
- **session:** implement session lifecycle and power management (Milestone M6)
- **session:** implement session integration and process supervision (Milestone M5)
- **build:** add DAZEOS_QUICK quick-repack mode to build-image.sh
- **wm:** implement minimum usable floating WM (Milestone M4)
- **boot:** add dual-firmware (UEFI + BIOS) hybrid ISO support (Milestone M1)
- **wm:** implement native X11 integration via JNA (Milestone M3)
- complete milestone M2 - robust session launcher and diagnostics
- **demo:** add cursor initialization and button click feedback
- complete milestone M0 - reproducible Debian live ISO build

#### Fixes

- **handbook:** Mermaid diagrams in the offline handbook
- **build:** local builds take the version channel from the branch
- **wm:** close the desktop root menu on clicks outside it
- **wm:** do not frame the desktop root menu's anchor window
- **dm:** set the worker's loginuid before starting the JVM
- store desktop settings under $XDG_CONFIG_HOME
- **wm:** make all Xlib calls from the event loop thread
- start applications detached instead of on unread pipes
- **panel:** close drawer popup on second click of drawer triangle button
- **build:** patch live-build lb_chroot_archives to avoid gpg error with drop-in deb packages
- **ui:** eliminate Metal blue gradients and style CheckBoxMenuItem with Motif 3D checkmarks
- **panel:** use MotifButtonBorder with margin support across dock widgets
- **ui:** eliminate button border mutation during paint to stop cursor flickering and repaint thrashing
- **dm:** resolve session startup flicker, X11 access control, and environment propagation
- **dm:** ensure live user dazeos always succeeds authentication and account management
- **dm:** add German keyboard layout support, greeter layout switcher, and live user authentication resilience
- **dm:** enable dazeos-dm service in systemd targets and add Xorg launch wrapper
- **panel:** prevent duplicate dock panels and implement Freedesktop icon theme standard
- **wm:** resolve double free crash and cascade cleanup on window close/minimize
- **wm:** preserve moved window positions when new windows open
- **wm:** align right corner notches with most right button and raise titlebar surface
- **wm:** fix Motif button alignment, corner joints, and dialog configure requests
- **wm:** implement ICCCM WM_TAKE_FOCUS and dynamic button grab to eliminate focus delay
- **build:** clean old ISO before xorriso and avoid unnecessary sudo in package-only mode
- **build:** reclaim binary ownership and support DAZEOS_PACKAGE_ONLY
- **input:** resolve Xorg mouse and keyboard input permissions
- **live:** add user-setup and sudo for live autologin

#### Other changes

- Conventional Commits, versions and release branches (#81)
- describe the current system instead of the first prototype
- license amadeOS under the EUPL-1.2
- update ROADMAP.md with 10-slot CDE front panel, NsCDE icons, and Motif L&F hardening
- **contributing:** document independent application development and deb packaging
- **roadmap:** mark M10 (XDG app discovery & deb apps) completed
- replace all remaining dazeos references with amadeos across scripts, configs, hooks, and codebase
- **roadmap:** add M10 (XDG app discovery & deb apps) and M11 (virtual workspaces & root menu)
- **desktop:** retire SwingDemoApplication in favor of CDE Front Panel as primary shell
- **roadmap:** mark M8 complete and record native X11 root window background decision
- **roadmap:** mark milestone M7 as completed
- **roadmap:** add milestones M6-M10 and desktop architecture diagrams
- **roadmap:** record M1 BIOS boot and mouse interaction verification
