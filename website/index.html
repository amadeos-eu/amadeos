Digital sovereignty starts on your desktop.

amadeOS is a free, European desktop operating system. Debian and Linux underneath, and on top a calm, classic desktop written entirely in Java, with its own applications and games. Open source from the login screen to the text editor, under the EU's own licence.

Why amadeOS

Your computer should work for you, not for the company that made its software. amadeOS is built so that you can see, understand and keep everything it does.

Open source, all the way up

Everything from the login screen to the text editor is free software under the EUPL-1.2, a licence published by the European Commission and valid in every official EU language.

Built on proven foundations

Debian Stable as the base, Linux as the kernel, Xorg as the display. amadeOS adds a desktop, not a new platform you have to trust.

Understandable

The whole desktop is plain Java and Swing: one codebase, one language, readable by anyone who wants to know what their system does.

Open standards, no lock-in

Programs are ordinary Debian packages with Freedesktop entries, files stay in open formats, and any X11 program runs next to the amadeOS applications.

A desktop that stays

A front panel, workspaces and clear window frames in the tradition of CDE, without a redesign every year. What you learn today still works in ten years.

No tracking

No account, no telemetry, no advertising. Firefox comes with telemetry off and an ad blocker on, and your mail, calendar and contacts stay on your computer.

A classic desktop, made new

The amadeOS desktop follows the Common Desktop Environment of the 1990s: a Front Panel with drawers, four named workspaces, Motif window frames and one place for all settings. Its display manager, window manager, panel and settings are new programs in Java.

Get amadeOS

amadeOS comes as one image file for a USB stick. It starts as a live system that changes nothing on your computer, and installs onto the disk from there, on its own or next to Windows.

Not released yet. The first release will be offered here for download, with its checksum and a list of every package in it. Until then you build the image yourself from the source code with one script.
git clone https://github.com/datazuul/amadeos.git
cd amadeos
./buildDistribution.sh

The script fetches and builds the desktop, the applications and the games and writes artifacts/amadeos-amd64.iso. It needs Debian or Ubuntu with Java 25 and live-build. Chapter 11 of the handbook explains every step, chapter 12 how to write the stick.

You can check what is in the image, not only that it arrived intact: the whole source code is public, and anyone can build the same image from it.
