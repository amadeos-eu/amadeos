# amadeOS 1.2.0

Released on 7 November 2026. Changes since amadeOS 1.1.0 in every repository of the distribution.

[Release page of amadeos 1.2.0](https://github.com/amadeos-eu/amadeos/releases/tag/v1.2.0) · the newest image: [www.amadeos.eu/download.html](https://www.amadeos.eu/download.html)

## Highlights

- **Calls**: video and audio calls between amadeOS computers in the local network, end-to-end encrypted,
  with screen sharing, chat with pictures and files, and call buttons in Contacts.
- **Font Viewer**: browse, compare and install fonts; free office-compatible fonts (Liberation, Carlito,
  Caladea, Noto) are in the image.
- **New logo** in the boot menu, the default wallpaper, the screen saver and the Horizon top bar.
- **Login and lock screens in the Horizon look.**
- **New programs arrive with updates**: the package `amadeos-desktop` recommends every program of
  amadeOS, so installed systems get new ones (like Calls and Font Viewer) with their next update.
- **Software** marks several packages and applies them in one run.
- **Lava Lamp** screen saver with six colour sets.
- Book Editor with icon toolbar; Terminal shows the real user in its preview; dialogs stay above their
  window; widgets can be moved and right-clicked again.
- Handbooks: pictures in the Horizon Dark look, open full size with a click.
