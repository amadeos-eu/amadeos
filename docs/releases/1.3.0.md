## amadeOS image and User's Handbook

### amadeos [1.3.0](https://github.com/amadeos-eu/amadeos/releases/tag/v1.3.0)

#### Features

- **build:** buildOptionalPackages.sh for the optional packages
- **image:** ship only Mines and Solitaire, other games optional
- Label Printer in the image, .label files open in it, handbook section
- Family Tree in the image, GEDCOM files open in it, handbook section
- Cruise in the image, the User's Handbook and the ROADMAP
- Pinball, the 19th game
- **audio:** tracker modules in the Audio Station

#### Other changes

- programs depend on amadeos-java-options
- launchers read the shared amadeOS Java options
- **handbook:** explain the new login after a Java update
- **handbook:** explain how amadeOS checks for updates daily
- **handbook:** New File, Open Terminal Here and the folder menus in Files
- **handbook:** Cruise shows the way to the next fork
- **handbook:** the relationship view shows the whole way
- **handbook:** Relationship to Home Person opens the chart
- **handbook:** Family Tree home person frame
- **handbook:** Family Tree relationship view
- **handbook:** Cruise's automatic graphics
- **handbook:** correct the Notepad++ comparison
- **handbook:** syntax colours, indentation and formatting in the Text Editor
- **releases:** release notes of all repositories per amadeOS release
- PR numbers for Pinball

### amade-game-engine [1.2.0](https://github.com/amadeos-eu/amade-game-engine/releases/tag/v1.2.0)

#### Features

- **drive:** cliffs are bodies of rock, not curtains
- **drive:** a road fast enough for full screen, and an automatic render mode
- **drive:** sight, mist and fog colour for weather on the road
- **audio:** mixer beds, streamed music and music volume
- **drive:** pseudo-3D road package and mixer drone
- **input:** tell the left and right Shift and Control keys apart
- **pinball:** captive balls held inside a fence
- **pinball:** pinball package with table physics, perspective and relief drawing

#### Fixes

- **pinball:** a ball leaning on a part rolls along it instead of creeping
- **drive:** shared pixel budget for sprite copies, steady fog colour, nearest-pixel sprite blits

#### Other changes

- **handbook:** only Mines and Solitaire come with the image
- **handbook:** Cruise's pictures with whole heads, and the first car
- **handbook:** quote Cruise with its gorges
- **handbook:** quote Cruise with the sky in the size of the screen
- **handbook:** rendered pictures in chapter 70, pin the pinball game
- **handbook:** chapter 70 step 10, tables rendered in Blender
- **handbook:** chapter 61 Cruise, the road games' trick in Part VI
- **handbook:** chapter 70 Pinball opens Part VII
