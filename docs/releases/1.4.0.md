## amadeOS image and User's Handbook

### amadeos [1.4.0](https://github.com/amadeos-eu/amadeos/releases/tag/v1.4.0)

#### Features

- **image:** add zram swap and earlyoom through amadeos-memory
- Music Studio as an optional package, handbook section
- Art Studio only as an optional package, not in the image

#### Fixes

- **image:** list trixie-updates only once

- Music Studio styles Heavy Metal, Rock, Pop, Lounge, Jazz and Reggae
- **handbook:** File Manager places bar in the two-panel view
- **handbook:** File Manager back/forward/up/home buttons and repair of disconnected disks
- Music Studio movements over the whole piece
- Music Studio with voices, pad, arpeggio, variety and harmony
- **roadmap:** #200 came after 1.3.0
- **roadmap:** amadeOS 1.3.0 released
- **releases:** notes of amadeOS 1.3.0
