# E. What Is Planned

The *Planned* boxes of this book, collected in one place, sorted by where they belong. The milestones (M12 and so on) are those of the [ROADMAP](https://github.com/amadeos-eu/amadeos/blob/main/ROADMAP.md), where the plan is kept up to date. Contributions to any of them are welcome.

## The system

| What | Milestone | Chapter |
|---|---|---|
| Signed images and a release manifest that lists every package | M12 | 6, 11 |
| A live stick that starts with Secure Boot on | M12 | 13 |
| A keyring service of amadeOS's own, in Java | M12 | 58 |
| Disk encryption, a separate home partition, shrinking a partition in the installer | M14 | 14, 58 |
| The clock settled between Windows and amadeOS | M14 | 15 |
| Moving to the next Debian release | M16 | 52 |
